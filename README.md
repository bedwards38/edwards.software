# edwards.software


[`edwards.software`](https://edwards.software) acts as my "portfolio", "curriculam vitae", "extended-form resume", or whatever else you'd like to call it. Simply put, I just wanted a place to showcase my personal projects and professional experience to anyone that might be interested: family, friends, colleagues, recruiters, hiring managers, you get the gist.

This project was built with the combination of [Astro 6](https://astro.build/) and TypeScript, initially using an [open-source template designed by 686f6c61](https://github.com/686f6c61/Portfolio-Astro-Template/tree/6313417a73d5e35fa03335080cc6e1988496cc03).

### A Note on AI Usage
In this day and age, I feel it's important to be open and honest about the use of AI in the development of a project.

AI was not used in the initial development of this project. However, I have since begun working with [Claude](https://claude.ai/code) as a pair programmer to introduce visual design changes, improve consistency across the site, and address bugs.

Commits that include work developed in collaboration with Claude are prefixed with `claudit(s): ` so that AI-assisted contributions are clearly identifiable in the project history.
