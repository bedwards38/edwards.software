## CSSE Teaching Assistant
*Rose-Hulman Institute of Technology | Nov 2020 - May 2022*

During my first two years of undergrad at Rose-Hulman Institute of Technology, I was a teaching assistant (TA) for various courses in the Computer Science and Software Engineering department. 

### Responsibilities
In this role, I assisted other students in learning the basics of software engineering -- including object-oriented design, data structures, and algorithm optimization/analysis.

The exact responsibilities I had differed for each course; however, there was a key set of functions I performed throughout my entire time as a TA:
- Conducted regular weekly office hours, offered one-on-one code reviews, and monitored online Q&A response forums to provide near 24/7 student assistance
- Guided students in class with their understanding of the key fundamentals of the Python and Java programming languages by encouraging them to interactively engage with the lesson material
- Contributed to grading tasks, evaluating student assignments and providing constructive feedback on their code quality, design decisions, and overall understanding of software engineering principles
- Participated in the development and review of new course materials, including quizzes, handouts, and strategies to address struggling students 

This experience not only helped me refine my own skills as an engineer but also gave me valuable insight into how others think through problems.

### Course List
These are the specific courses I was a TA for -- each includes the language used, dates of assignment, and a short description:

##### Introduction to Software Development 
  - ***Language***: Python
  - ***Dates of Assignment***: Nov 2020 - Nov 2021
  - ***Description***: Course material covered introductory programming concepts, including code tracing, variables, data types, debugging, control flow structures, GUIs, and API consumption

##### Object-Oriented Software Development
  - ***Language***: Java
  - ***Dates of Assignment***: Nov 2021 - Feb 2022
  - ***Description***: Early course material covered object-oriented programming principles, including polymorphism, encapsulation, coupling, and cohesion -- later course material focused on more advanced concepts like simple design patterns, UML construction, event handling, simple recursion, and simple algorithm analysis

##### Data Structures & Algorithm Analysis
  - ***Language***: Java
  - ***Dates of Assignment***: Nov 2021 - Feb 2022
  - ***Description***: Early course material covered the implementation of both native and custom data structures, including stacks, queues, trees, hash tables, graphs, and sets -- later course material focused on recursive data structures and the evaluation of a data structure's space/time complexity when used in algorithms
