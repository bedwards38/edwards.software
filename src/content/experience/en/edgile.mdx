### Initiatives

> Since these initiatives were for systems belonging to clients of Edgile/Wipro, I cannot discuss any specific design or implementation details

#### Integration with On-Premises Directory System

I led the effort to connect our web services to the client's on-premises directory system using the Ping UnboundID LDAP SDK. This involved rearchitecting the existing project to adopt a standard object-model design commonly used in Spring Boot applications. 

The successful initiative enabled read and write access to the client's directory system for users accessing our web service. To future proof our solution, we designed the integration to be platform agnostic, with the ability to adapt to evolving directory system requirements. 

#### Application Load Testing
To ensure the scalability and performance of our web services under heavy traffic conditions, we conducted an extensive load testing effort that I managed. To accomplish this, I researched and learned the JMeter -- a widely-used load testing tool -- and desgined an exhaustive test plan that could be easily extended or modified as needed. 

Using JMeter, we were able to successfully simulate heavy loads on the system, which revealed potential performance bottlenecks and areas for optimization in the application. After identifying and addressing these issues, I documented the entire load testing process and continue to maintain the load test plan for future development efforts.

#### OpenAPI Documentation Integration
To improve efficiency, I spearheaded an initiative to move away from manually documenting the various API specifications for our web services. Instead, we refactored our existing application to embed OpenAPI annotations, which are used to generate various API specifications on-demand using SpringDoc.

By leveraging SpringDoc's automated generation capabilites, we were able to to ensure that our API specifications remained synchronized with our codebase, facilitating easier maintenance and understandability.
