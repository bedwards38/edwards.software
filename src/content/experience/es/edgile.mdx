### Iniciativas

> Dado que estas iniciativas eran para sistemas pertenecientes a clientes de Edgile/Wipro, no puedo comentar detalles específicos de diseño o implementación

#### Integración con el Sistema de Directorios Locales

Lideré el esfuerzo de conectar nuestros servicios web al sistema de directorio local del cliente usando el SDK LDAP UnboundID de Ping. Esto implicó la rearquitectura del proyecto existente para adoptar un diseño de modelo de objeto estándar comúnmente utilizado en aplicaciones Spring Boot.

La exitosa iniciativa permitió el acceso de lectura y escritura al sistema de directorios del cliente para los usuarios que acceden a nuestro servicio web. A prueba de futuro de nuestra solución, diseñamos la integración para ser independiente de la plataforma, con la capacidad de adaptarse a los requisitos cambiantes del sistema de directorios.

#### Pruebas de Carga de Aplicaciones
Para garantizar la escalabilidad y el rendimiento de nuestros servicios web bajo condiciones de tráfico intenso, realizamos un extenso esfuerzo de pruebas de carga que gestioné. Para lograr esto, investigué y aprendí el JMeter, una herramienta de prueba de carga ampliamente utilizada, y diseñé un plan de prueba exhaustivo que podría ampliarse o modificarse fácilmente según fuera necesario.

Usando JMeter, pudimos simular con éxito cargas pesadas en el sistema, lo que reveló posibles cuellos de botella de rendimiento y áreas para la optimización en la aplicación. Después de identificar y abordar estos problemas, documenté todo el proceso de pruebas de carga y continúo manteniendo el plan de pruebas de carga para futuros esfuerzos de desarrollo.

#### Integración de Documentación OpenAPI
Para mejorar la eficiencia, encabezé una iniciativa para dejar de documentar manualmente las diversas especificaciones de API para nuestros servicios web. En su lugar, refactorizamos nuestra aplicación existente para incrustar anotaciones de OpenAPI, que se utilizan para generar varias especificaciones de API bajo demanda usando SpringDoc.

Al aprovechar las capacidades de generación automatizada de SpringDoc, pudimos asegurarnos de que nuestras especificaciones API permanecieran sincronizadas con nuestro código base, lo que facilitó el mantenimiento y la comprensión.
